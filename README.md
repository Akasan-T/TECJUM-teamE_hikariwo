## 📌 概要

サントリーグローバルイノベーションセンター（GIC）様との産学連携プロジェクトとして、
チームで企画・制作したWebシステム／ランディングページです。
要件定義から設計・実装・リリースまでのフルサイクルをチームで担当しました。
